# Архив нашей памяти — квест-сайт

## Что тут есть
```
lovestory/
├── index.html      ← сама страница, трогать не нужно
├── style.css       ← оформление, трогать не нужно
├── script.js       ← логика, трогать не нужно
├── config.js       ← ВСЁ, ЧТО РЕДАКТИРУЕШЬ ТЫ (имя, даты, тексты)
└── images/         ← СЮДА КЛАДЁШЬ ФОТО
```

## Как добавить фото — 2 шага

**Шаг 1.** Открой папку `images/` и положи туда 5 фотографий с этими
точными названиями (регистр и расширение важны):

| Файл | Что это |
|---|---|
| `level1.jpg` | Уровень 1 — ваше знакомство |
| `level2.jpg` | Уровень 2 — первое свидание |
| `level3.jpg` | Уровень 3 — самое тёплое воспоминание |
| `level4.jpg` | Уровень 4 — свежее совместное фото |
| `gift.jpg` | Финал — фото самого подарка |

Если фото не `.jpg`, а `.png` — просто открой `config.js` и поменяй
расширение в соответствующей строке (например `images/level1.png`).

**Шаг 2.** Открой `config.js` и замени:
- `girlName` — имя,
- `date` в каждом уровне — реальные даты,
- при желании — тексты `startSubtitle`, `finalTitle`, `finalMessage`.

Пока файлов нет — на их месте аккуратно показывается плейсхолдер с
подсказкой, какой файл туда положить, так что сайт не сломается и
можно проверять вёрстку заранее.

## Как посмотреть локально
Просто дважды кликни `index.html` — откроется в браузере. Либо, если
есть Python: `python3 -m http.server` в этой папке и открыть
`http://localhost:8000`.

## Как выложить на GitHub Pages
1. Создай новый репозиторий на GitHub.
2. Загрузи в него всё содержимое папки `lovestory/` (включая `images/`
   с уже добавленными фото).
3. Settings → Pages → Source → выбери ветку `main` / папку `root`.
4. Через минуту сайт будет доступен по ссылке вида
   `https://твой-логин.github.io/название-репозитория/`.

## Что можно донастроить в `config.js`
- `giftCount` — сколько иконок-подарков в сердце на финальном экране (сейчас 8).
- `autoAdvanceSeconds` — через сколько секунд уровень листается сам
  (0 — только вручную кнопкой «Дальше»).
